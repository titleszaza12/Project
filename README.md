# Study Plan System

ระบบวางแผนการเรียนและตรวจสอบเงื่อนไขการสำเร็จการศึกษา สำหรับนักศึกษาสาขาเทคโนโลยีสารสนเทศ  
พัฒนาขึ้นเพื่อช่วยให้นักศึกษาสามารถตรวจสอบแผนการเรียนของตนเอง จัดการรายวิชาที่ต้องลงทะเบียน และประเมินความพร้อมในการจบการศึกษาได้อย่างเป็นระบบ

## วัตถุประสงค์ของระบบ

ระบบนี้ถูกออกแบบมาเพื่อแก้ปัญหาการวางแผนการเรียนที่ซับซ้อน เช่น

- รายวิชาที่มีเงื่อนไขก่อนเรียน
- การเก็บหน่วยกิตให้ครบตามหลักสูตร
- การตรวจสอบหมวดวิชาและวิชาบังคับ
- การติดตามความคืบหน้าในการเรียน
- การตรวจสอบว่านักศึกษาผ่านเกณฑ์จบการศึกษาหรือไม่

## ความสามารถหลักของระบบ

### 1. สมัครสมาชิกและเข้าสู่ระบบ
ผู้ใช้งานสามารถสมัครสมาชิกและเข้าสู่ระบบด้วยรหัสนักศึกษาและรหัสผ่าน เพื่อใช้งานระบบได้อย่างปลอดภัย

### 2. จัดการข้อมูลส่วนตัว
ผู้ใช้สามารถดูและแก้ไขข้อมูลพื้นฐานของตนเอง รวมถึงอัปโหลดรูปโปรไฟล์ได้

### 3. ดูรายวิชาทั้งหมดในหลักสูตร
ระบบแสดงข้อมูลรายวิชาทั้งหมดที่เกี่ยวข้องกับหลักสูตร เช่น
- รหัสวิชา
- ชื่อรายวิชา
- จำนวนหน่วยกิต
- หมวดวิชา
- เงื่อนไขก่อนเรียน

### 4. วางแผนการเรียน
นักศึกษาสามารถสร้างและจัดการแผนการเรียนของตนเอง โดยเลือกวิชาลงในแต่ละภาคการศึกษา เพื่อช่วยให้เห็นภาพรวมของแผนการเรียนตลอดหลักสูตร

### 5. ตรวจสอบความถูกต้องของแผนการเรียน
ระบบรองรับการตรวจสอบเงื่อนไขต่าง ๆ ของหลักสูตร เช่น
- Prerequisite (เงื่อนไขก่อนเรียน)
- Credit Requirement (จำนวนหน่วยกิตรวม)
- Course Group (หมวดวิชา)
- Mandatory Courses (วิชาบังคับ)
- Study Plan Sequence (ลำดับการเรียนตามความเหมาะสม)
- Track Requirement (เงื่อนไขเฉพาะของแทร็ก)
- Graduation Check (ตรวจสอบจบการศึกษา)

### 6. ตรวจสอบจบการศึกษา
ระบบสรุปผลการตรวจสอบว่าผู้ใช้ผ่านหรือยังไม่ผ่านเกณฑ์การจบการศึกษา พร้อมแสดงรายละเอียดในแต่ละด้านที่ยังขาดหรือยังไม่ครบ

## เทคโนโลยีที่ใช้

โครงสร้างของระบบแบ่งออกเป็น 2 ส่วนหลัก ได้แก่

### Frontend
ใช้สำหรับพัฒนาหน้าจอและประสบการณ์การใช้งานของผู้ใช้

### Backend
ใช้สำหรับจัดการข้อมูล ประมวลผลกฎทางธุรกิจ และเชื่อมต่อฐานข้อมูล

### Database
ใช้สำหรับจัดเก็บข้อมูลผู้ใช้ รายวิชา แผนการเรียน ผลการเรียน และข้อมูลที่เกี่ยวข้องกับการตรวจสอบจบ

## ประโยชน์ของระบบ

- ช่วยให้นักศึกษาวางแผนการเรียนได้ง่ายขึ้น
- ลดความผิดพลาดในการลงรายวิชา
- ช่วยตรวจสอบเงื่อนไขการเรียนและการจบได้อย่างเป็นระบบ
- ทำให้มองเห็นความคืบหน้าของตนเองได้ชัดเจน
- สนับสนุนการตัดสินใจในการวางแผนเรียนระยะยาว

## กลุ่มผู้ใช้งาน

ระบบนี้เหมาะสำหรับ
- นักศึกษา
- อาจารย์ที่ปรึกษา
- ผู้ดูแลระบบการศึกษา
- ผู้พัฒนาระบบที่ต้องการต่อยอดระบบตรวจสอบจบการศึกษา

## ภาพรวมการทำงานของระบบ

1. ผู้ใช้สมัครสมาชิกและเข้าสู่ระบบ
2. ผู้ใช้เลือกดูรายวิชาและสร้างแผนการเรียน
3. ระบบบันทึกข้อมูลแผนการเรียน
4. ระบบตรวจสอบเงื่อนไขตามหลักสูตร
5. ระบบแสดงผลสรุปการผ่านหรือไม่ผ่านเกณฑ์จบ
6. ผู้ใช้สามารถปรับแผนการเรียนให้เหมาะสมได้จากผลการตรวจสอบ
